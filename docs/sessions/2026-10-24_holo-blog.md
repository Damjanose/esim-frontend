# Session: holo-blog

## What existed before
`/blog` and `/blog/:slug` were 308s to `/travel` (f270). No blog pages.

## What was done
- `/blog` index and `/blog/[slug]` post pages (content-page styling, `.blog-prose` for CMS HTML, BlogPosting + Breadcrumb JSON-LD, metaTitle/metaDescription/canonical/OG image).
- `POST /bff/blog/revalidate` (HMAC with `HOLO_WEBHOOK_SECRET`) → `revalidatePath` for the index, the post(s) and sitemaps.
- Async `/sitemaps/blog.xml` part, listed in `/sitemap.xml` once posts exist.
- Footer link "eSIM2you blog". Removed the two `/blog` redirects from `next.config.mjs`.
- `README.md` (new) documents the flow and env vars.
- Tests: `src/lib/blog.test.ts`, `src/app/bff/blog/revalidate/route.test.ts`. Build verified; end-to-end smoke test (local backend + scratch Postgres + `next start`) showed publish → revalidate → post visible on `/blog`.

## Decisions
The webhook lives in the backend (nginx routes `/api` there; DB is backend Postgres). See backend session 2026-10-24_holo-blog-webhook.

## Follow-ups
Set `HOLO_WEBHOOK_SECRET` in `/var/www/esim-frontend/.env.production`, same value as the backend. Visitors' browsers may have cached the old permanent 308 `/blog` → `/travel`.
