# Session: soro-blog

## What existed before
`/blog` and `/blog/[slug]` were the Holo blog: server-rendered from the backend's `GET /api/blog`, ISR with a `blog` cache tag, refreshed by the backend's signed POST to `/bff/blog/revalidate`, with its own `/sitemaps/blog.xml` part (f299, f326).

## What was done
- `/blog` now hosts the Soro (trysoro.com) embed. `src/app/blog/SoroBlog.tsx` renders `#soro-blog` and appends the embed script on every mount, so a client-side navigation back to `/blog` still renders posts. Soro opens posts in place at `/blog?post=<slug>`.
- Holo removed: `src/lib/blog.ts` (+ test), `/blog/[slug]`, `/bff/blog/revalidate` (+ test), `.blog-prose` CSS, `HOLO_WEBHOOK_SECRET` in `.env.example`.
- `/blog/:slug` 308s to `/blog`. `/blog` is a static `indexableRoutes` entry, `/sitemaps/blog.xml` is gone, and both sitemap routes are static again.

## Outcome
Build, type-check and all tests pass. Soro post content renders in the browser, so it is not in the server HTML. The backend's Holo webhook to `/bff/blog/revalidate` now gets 404, and turning it off is a backend change (f370-f371).
