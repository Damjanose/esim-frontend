# Partner promo materials — designer brief

This is the brief for the 7 promo template files needed on the eSim2you partner
materials page. Deliver files with the exact filenames below into
`public/partner-materials/` in this repo — no need to wait until all 7 are ready,
send them as they're finished.

## Brand assets to use

- **Logo**: `public/logo-full.png` (horizontal lockup, use where there's room) or
  `public/logo-icon.png` (mark only, for tight/square layouts).
- **Colors**:
  - Primary: `#0B49B7` (brand blue)
  - Accent: `#09C3BE` (brand teal)
  - Text/dark: `#061131` (brand ink)
  - Light backgrounds: `#dff6fa` (mist) or `#f4fbfd` (cloud)
- **Fonts**: Headlines in **Hanken Grotesk**, bold/black weight. Body copy in **Inter**.

## Hard constraint — read this first

**Do not add a QR code or promo code to any template.** Each partner gets their own
unique QR code and promo code, generated and shown separately on their dashboard —
never baked into the shared artwork. Instead, every template must leave a clearly
reserved empty space (a corner box or dedicated panel) for the partner to add their
own code — label it in your working file as "Partner QR code + promo code go here"
so the layout is sized around it, but the delivered file should just show the empty
space.

## Suggested copy

Pull from these value props for headlines/bullets — mix and match per format:
- Instant activation — no physical SIM swap
- Works the moment you land
- No roaming bill surprises

Suggested CTA: "Scan or use your code to get connected."
